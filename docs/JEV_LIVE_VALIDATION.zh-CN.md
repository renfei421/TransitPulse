## 正负数值已能真实返回

双对象构造样本表达“油价难以负担，但公交便宜、可靠、舒适”。v2 实际结果：

|---|---:|---|
| 公共交通 | +1.00 | 明确表达、正面 |
| 燃油费用 | −1.00 | 明确表达、负面 |

| 燃油车驾驶 | null | 没有明确对驾驶本身的评价 |

分数采用 `P(positive) − P(negative)`；原生 Score、三档概率、confidence 分开保存。

这不是满意百分比，也不是已经校准的情绪强度。

## 修正的实际问题

1. **数值舍入**：真实返回过 `score=1.01` 和概率 `[0,0.98,0.02]`，后者期望为 1.02。
   适配器原先要求误差不超过 1e-5，导致误拒绝。现在只对百分位网格数字允许有限舍入误差，
   三档 score 最大容差 0.02；保留原值、概率总和和期望差值，不自动重写概率。
2. **不同对象之间的态度转移**：v1 在双对象样本中额外赋予燃油车驾驶 −0.85。
   v2 明确区分费用与驾驶评价、行为与态度、泛指汽车与燃油车，当前该例改为 null。
3. **作者归属**：v1 接受了 S008 的公交引文、S013 的充电新闻、S024/S026 的油价文章摘录。
   v2 要求引用或摘录之外另有作者明确评价，四条均改为 factual_only/null。
   S024 和 S026 是近重复内容，不应当成两份独立观点。

v2 没有修改模型权重、没有微调。变更在 instructions、criteria 和对象定义中，
使用新合约哈希隔离缓存，保存 v1/v2 原始结果供对照。

## 未解决的质量与数据问题

初始 30 条在 v2 中有 22 条可赋予整帖语气分数：正面 4、中立 12、负面 6；
另有 mixed 1、unclassified 7。它们是全样本的文本语气，包括与业务主题无关的帖子，
不能称为公众对交通的总体态度。内容类型判定为新闻/链接摘要 20、观点 7、其他 2、推广 1。
18 条被判 related，其中 14 条的相关性 confidence 达到暂定阈值 0.6。

v1 接受 4 条对象态度，v2 接受 0 条，说明作者归属约束产生了很强的拒绝效果；
不能把“接受更少”自动称为精度提升。对 S021 的列车故障抱怨、S029 的 EV 讽刺，
仍有置信度或相关性门槛导致的漏判风险。

另选本人经历样本的 v2 结果如下（短描述为审核摘要，非模型解释）：

| 样本 | 内容概要 | 对象结果 | 审核结论 |
|---|---|---|---|
| P01 | 充电设备兼容、预授权费用更低 | EV +0.96 | 符合明确的本人正面评价 |
| P02 | 乘电车刷卡时意外触发钱包扣费 | 公交 null | 负面体验被拒绝，需判断票务是否纳入服务态度 |
| P03 | 深夜乘电车及时到达药店 | 公交 +0.99 | 识别到对公共交通的认可 |
| P04 | 骑电动自行车替代短途驾车、省油钱 | 所有目标 null | 没有把电动自行车直接当乘用 EV；部分中间状态仍需复核 |
| P05 | 因驾照不再有欧盟标志而感到难过 | 所有目标 null | 没把政治情绪当驾驶态度 |
| P06 | 正在进行 EV 长途体验，报告电量 | EV null | 尚未表达评价，保留事实 |
| P07 | 不同充电站有好有坏 | EV mixed/null | 褒贬混合不强行平均成中立 |
| P08 | 两辆同线路公交发车安排让人困惑不满 | 公交 null | 已识别 expressed，但状态 confidence 未过门槛，存在漏判 |

八条均被模型判为 personal_experience，七条有整帖语气分数，仅两条有通过门槛的对象态度。
不能为了得到更多数字直接降低所有阈值；应先定义票务/服务边界，并用独立标注分别校准
相关性、作者归属与情感置信度。此轮不声称 Jev 比 RoBERTa 或 GPT 更准确。

六个构造诊断覆盖双对象、事实通知、明确未赞同的引文、同对象褒贬混合、明显讽刺及一条
简单指令注入。按提前写下的诊断检查，v1 为 5/6，v2 为 6/6；这只说明这些例子符合期望，
不是泛化准确率或全面的抗注入保证。v2 规则开发用过这些样本，不是独立测试集。
