# 四分钟演示与录制脚本

录制对象：`frontend/transitpulse.html` 的冻结汇总页，以及通过归档恢复的本地 API。明确说明是已完成实验的回放，不伪装成正在发生的采集或推理。公开版本不要录入私有帖子、密钥、账号或账单身份信息。

| 时间 | 画面与操作 | 讲解 |
|---|---|---|
| 0:00–0:35 | 页首数据规模和窗口 | “我们观察能源价格变化窗口中的交通讨论。采集后有 124,491 条去重帖子，90,576 条进入固定模型，结果全部完成。” |
| 0:35–1:10 | 燃油成本曲线与采集量 | “讨论量和有效态度不是一个概念。每天至少五条有效态度；分页受限的日期从主要分析排除。空白不是中性，也不会补零。” |
| 1:10–1:40 | 切换公共交通、EV | “同一条帖子可以对不同目标持相反态度。整体语气与对象态度分离，分数与 confidence 也分离。” |
| 1:40–2:10 | 切换 Mastodon | “补充平台的有效态度太少，不能为了画完整曲线就把缺失填满，也不能把平台样本合并成总体民意。” |
| 2:10–2:45 | 油价图和主要发现 | “52 个有效日期对中没有明显的同期线性关联。这个描述性检验不是因果推断。” |
| 2:45–3:20 | 架构图和费用回执证据 | “请求先预留费用，再保存原生响应和结果；已有响应可以恢复，未知失败仍计入预算，每条最多三次付费预留。” |
| 3:20–4:00 | 恢复报告、API 校验和限制 | “完整文档已归档，恢复后核对全部指纹，再比较云端与本地 API。展示不需要继续支付云费用；模型质量仍需人工金标评测。” |

不要把仅截图切换的演示称为连续运行录像；若使用截图讲解，注明形式。原云端运行证据保存在版本化 JSON 和报告中。

已生成本机成果：`artifacts/transitpulse-walkthrough.mp4`，4 分钟，1920×1080，真实页面截图讲解版，无配音，带可选中文字幕轨及同名 `.srt`。这是六个界面的定时回放，不是云端运行录屏。播放器未显示字幕时可手动启用中文轨。
